DA.live Library Setup

Follow these steps to populate the Library in DA.live.

Step 1: Create the Library spreadsheet

  1. Go to DA.live /tools/sidekick/
  2. Create a new sheet (not document) called library
  3. In the sheet, create a tab called helix-blocks
  4. Add columns: name and path
  5. Add this row: name = Blocks, path = /tools/sidekick/blocks
  6. Click Preview to publish

Step 2: Create the Blocks example document

  1. Go to DA.live /tools/sidekick/
  2. Create a new document called blocks
  3. Select the content below (Cmd+A inside the box), Copy (Cmd+C)
  4. Paste (Cmd+V) into the blocks document
  5. Click Preview to publish
